


vela 相关数据:
curve vela (流动池token)  =  curve.lpTokenReserve
borrow token (借贷池token) = curve.borrowTokenReserve
pool token (总锁仓token) =   curve.poolTokenAccount(这个地址上的token数量)
杠杆头寸上锁定的 token 数量  = 做多买入的token


sol 相关数据:
curve sol  (流动池sol) = curve.lpSolReserve
borrow sol (借贷池sol) = curve.borrowSolReserve
pool sol (总锁仓sol) =   curve.borrowSolReserve(这个地址上的sol数量)
sol保证金
杠杆头寸上锁定的 sol 借贷资金


curve sol  (流动池sol) 构成 = 初始虚拟池 + curve.borrowSolReserve


vela 相关数据:
curve vela (流动池token)   
borrow token (借贷池token)  2段组成 = 已借出的 + 未借出的
lock token (杠杆锁仓token)
(三者加起来 = curve.poolTokenAccount(合约地址上的所有token数量))

sol 相关数据:
curve sol  (流动池sol) 由3段组成 = 初始虚拟池 + 杠杆虚拟资金 + 真实sol资金
margin sol (sol保证金)
(真实sol资金 + sol保证金 = 合约地址上的所有sol数量)


curve vela (流动池token)   
curve sol  (流动池sol)

borrow token (借贷池token)  2段组成 = 已借出的 + 未借出的
lock token (杠杆锁仓token)
margin sol (sol保证金)
