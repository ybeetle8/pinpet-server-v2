# 升级方案_第三阶段_修改创币事件

## 📋 概述

本阶段将 `BorrowingBondingCurve` 账户结构中新增的动态流动池参数同步到 `TokenCreatedEvent` 事件中，使前端和索引器能够在代币创建时获取完整的池子配置信息。

**实施日期**: 2026-01-12
**状态**: ✅ 已完成
**相关阶段**:
- 第一阶段：动态流动池参数（`initial_virtual_sol`, `initial_virtual_token`）
- 第二阶段：高级版池子参数（`pool_type`, `borrow_pool_ratio`）

---

## 🎯 实施方案

### 方案选择：方案A - 完整同步所有新增字段

经过分析，采用完整同步方案，将 `BorrowingBondingCurve` 的4个新增字段全部同步到 `TokenCreatedEvent`：

| 字段名 | 类型 | 说明 | 来源阶段 |
|--------|------|------|----------|
| `initial_virtual_sol` | `u64` | 初始虚拟SOL储备量 (lamports, 9位精度) | 第一阶段 |
| `initial_virtual_token` | `u64` | 初始虚拟Token储备量 (最小单位, 9位精度) | 第一阶段 |
| `pool_type` | `u8` | 池子类型 (0=普通版, 1=高级版) | 第二阶段 |
| `borrow_pool_ratio` | `u8` | 借贷池代币占比 (5-30代表5%-30%) | 第二阶段 |

**方案优势**:
- ✅ 完整的池子配置信息，无需额外查询账户
- ✅ 便于前端区分普通版/高级版代币
- ✅ 支持按流动性大小筛选和排序
- ✅ 便于链下索引器构建完整的代币数据库
- ✅ 事件大小增量仅20字节，对链上成本影响极小

```rust
pub struct TokenCreatedEvent {
    pub payer: Pubkey,

    pub pool_token_account: Pubkey,
    pub pool_sol_account: Pubkey,

    pub uri: String,

    pub down_orderbook: Pubkey,            // 做多订单账本 (Down方向) PDA地址
    pub latest_price: u128,                // 最新的价格

    // ============ 新增字段：动态流动池参数 ============
    pub initial_virtual_sol: u64,          // 初始虚拟SOL储备量 (lamports, 9位精度, 默认30 SOL)
    pub initial_virtual_token: u64,        // 初始虚拟Token储备量 (最小单位, 9位精度, 默认10.73亿Token)

    // ============ 新增字段：高级版池子参数 ============
    pub pool_type: u8,                     // 池子类型: 0=普通版(默认参数+支持手续费减半), 1=高级版(自定义参数+手续费永不减半)
    pub borrow_pool_ratio: u8,             // 借贷池代币占比(5-30代表5%-30%, 普通版固定20, 仅用于信息展示)
}
```

**修改说明**:
- 在 `TokenCreatedEvent` 结构体末尾添加4个新字段
- 保持与 `BorrowingBondingCurve` 字段名称和类型一致
- 添加详细的中文注释说明字段含义

### 2. 计算初始市值

```typescript
import { Decimal } from 'decimal.js';

function calculateInitialMarketCap(event: TokenCreatedEvent): Decimal {
  const SOL_PRECISION = new Decimal(10).pow(9);
  const TOKEN_PRECISION = new Decimal(10).pow(9);

  const virtualSol = new Decimal(event.initial_virtual_sol.toString())
    .div(SOL_PRECISION);

  const virtualToken = new Decimal(event.initial_virtual_token.toString())
    .div(TOKEN_PRECISION);

  // 初始价格 = virtual_sol / virtual_token
  const initialPrice = virtualSol.div(virtualToken);

  // 市值 = 价格 × 总供应量
  const totalSupply = new Decimal(1_000_000_000); // 10亿代币
  return initialPrice.mul(totalSupply);
}
```

### 3. 按流动性筛选

```typescript
enum LiquidityTier {
  LOW = "低流动性",
  STANDARD = "标准流动性",
  HIGH = "高流动性",
  ULTRA = "超高流动性"
}

function getLiquidityTier(event: TokenCreatedEvent): LiquidityTier {
  const solAmount = Number(event.initial_virtual_sol) / 1e9;

  if (solAmount >= 100) return LiquidityTier.ULTRA;
  if (solAmount >= 60) return LiquidityTier.HIGH;
  if (solAmount >= 30) return LiquidityTier.STANDARD;
  return LiquidityTier.LOW;
}
```

## 🔄 向后兼容性

### 旧版本事件处理

对于升级前创建的代币，`TokenCreatedEvent` 不包含新字段，需要处理向后兼容：

```typescript
interface LegacyTokenCreatedEvent {
  // 原有字段...
  // 没有 initial_virtual_sol 等新字段
}

function handleTokenCreatedEvent(event: any) {
  // 判断是否为新版本事件
  if ('initial_virtual_sol' in event) {
    // 新版本：直接使用新字段
    return processNewVersionEvent(event as TokenCreatedEvent);
  } else {
    // 旧版本：使用默认值填充
    const legacyEvent = event as LegacyTokenCreatedEvent;
    return processLegacyEvent({
      ...legacyEvent,
      initial_virtual_sol: 30_000_000_000n,      // 默认30 SOL
      initial_virtual_token: 1_073_000_000_000_000_000n,
      pool_type: 0,                              // 默认普通版
      borrow_pool_ratio: 20,                     // 默认20%
    });
  }
}
```
