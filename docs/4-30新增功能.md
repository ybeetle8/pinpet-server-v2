

===pinpet 项目数据显示完善===

交易页主要显示字段: 
token流动池  字段: lpTokenReserve
sol流动池  字段: lpSolReserve
借贷池token  字段: borrowTokenReserve

交易页列表显示字段: 
token总发行量(初始流通量+初始借贷池)  字段:  totalSupply
初始流通token数量  字段: initialVirtualToken
实际token流通数量( 初始流通量 + 借币卖出数量) 字段:  circulatingSupply
合约真实锁定token总数   字段: poolTokenBalance = (下拉: token流动池+杠杆做多token锁仓数+借贷池token)
合约真实锁定sol总数  字段: poolSolBalance =(下拉: 现货买入的sol + 杠杆做多总保证金sol + 杠杆做空总保证金sol )
注: 现货买入的sol = 合约真实锁定sol总数 - 杠杆做多总保证金sol - 杠杆做空总保证金sol

*以上字段从 sdk 上的 getCurveAccount

杠杆做多总保证金sol 字段: long_margin_sol 
杠杆做多token锁仓数  字段: long_token_locked 
杠杆做多SOL借出数 字段: long_sol_borrowed

杠杆做空总保证金sol  字段:  short_margin_sol 
杠杆做空SOL锁仓数  字段:  short_sol_locked 
杠杆做空token借出数  字段:  short_token_borrowed

杠杆多空的统计在这里拿: 
以下2个接口增加了累计交易量的字段
GET /api/tokens/list 
GET /api/tokens/mint/{mint}
